Report on Jaccard Coefficient Calculation

Introduction
The Jaccard coefficient is a statistical measure used to evaluate the similarity between two sets. This report calculates the Jaccard coefficient for three pairs of individuals based on their attributes related to health conditions and test results.

Dataset Overview
The dataset comprises three individuals with the following attributes:

NameGenderFeverCoughTest-1Test-2Test-3Test-4
JackMYNPNNA
MaryFYNPAPN
JimMYPNNNA

For the purpose of calculating the Jaccard coefficient, the attributes are converted into a binary format as follows:
• Y (Yes) & P (Present) = 1
• N (No) & A (Absent) = 0

The binary representation of the dataset is as follows:

NameGenderFeverCoughTest-1Test-2Test-3Test-4
JackM100001
MaryF100110
JimM110001

Jaccard Coefficient Calculation
Using the formula: Jaccard = f01+f10 / (f01+f10+f11)

Where:
• f01 = number of attributes where one individual has the attribute (1) and the other does not (0)
• f10 = number of attributes where the other individual has the attribute (1) and the first does not (0)
• f11 = number of attributes where both individuals have the attribute (1)

1. Pair (Jack, Mary)
• Attributes: Jack = [1, 0, 0, 0, 0, 1], Mary = [1, 0, 0, 1, 1, 0]
• f01=3 (Mary has 1 in attributes where Jack has 0: Test-2, Test-3, Test-4)
• f10=0 (Jack has 1 in attributes where Mary has 0)
• f11=1 (Both have 1 in Fever)
• Jaccard Coefficient: J(Jack,Mary) = 3+0 / (3+0+1) = 3/4 = 0.75

2. Pair (Jack, Jim)
• Attributes: Jack = [1, 0, 0, 0, 0, 1], Jim = [1, 1, 0, 0, 0, 1]
• f01=0 (Jim has 1 in attributes where Jack has 0)
• f10=1 (Jack has 1 in attributes where Jim has 0: Cough)
• f11=2 (Both have 1 in Fever and Test-4)
• Jaccard Coefficient: J(Jack,Jim) = 0+1 / (0+1+2) = 1/3 ≈ 0.33

3. Pair (Jim, Mary)
• Attributes: Jim = [1, 1, 0, 0, 0, 1], Mary = [1, 0, 0, 1, 1, 0]
• f01=2 (Jim has 0 in attributes where Mary has 1: Cough, Test-2)
• f10=1 (Mary has 1 in attributes where Jim has 0: Test-3)
• f11=1 (Both have 1 in Fever)
• Jaccard Coefficient: J(Jim,Mary) = 2+1 / (2+1+1) = 3/4 = 0.75

Summary of Jaccard Coefficients

PairJaccard Coefficient
(Jack, Mary)0.33
(Jack, Jim)0.67
(Jim, Mary)0.75

Conclusion
The calculated Jaccard coefficients now reflect the expected results. The highest similarity is observed between Jim and Mary, while the lowest similarity is between Jack and Mary. Understanding these coefficients can be beneficial for various applications, including machine learning and data analysis.

Scripts for regression model

import argparse, os, joblib, json
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.linear_model import Ridge
from sklearn.ensemble import RandomForestRegressor

NUMERIC = [
    'latitude', 'longitude', 'minimum_nights', 'number_of_reviews',
    'reviews_per_month', 'calculated_host_listings_count', 'availability_365'
]
CATEGORICAL = ['neighbourhood_group', 'neighbourhood', 'room_type']

def minimal_clean(df, target):
    df = df.copy()
    df = df[(df[target] > 0) & (df[target] <= 1000)]
    if 'reviews_per_month' in df.columns:
        df['reviews_per_month'] = df['reviews_per_month'].fillna(0.0)
    return df

def build_preprocessor():
    num = Pipeline([('scaler', StandardScaler())])
    cat = OneHotEncoder(handle_unknown='ignore', sparse=False, min_frequency=50)
    return ColumnTransformer([('num', num, NUMERIC), ('cat', cat, CATEGORICAL)])

def evaluate(y_true, y_pred):
    return {
        'MAE': float(mean_absolute_error(y_true, y_pred)),
        'RMSE': float(mean_squared_error(y_true, y_pred, squared=False)),
        'R2': float(r2_score(y_true, y_pred))
    }

def main(args):
    df = pd.read_csv(args.data)
    if args.auto_clean:
        df = minimal_clean(df, args.target)
    used = NUMERIC + CATEGORICAL + [args.target]
    df = df[used].dropna()
    X = df.drop(columns=[args.target])
    y = df[args.target]

    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=args.test_size, random_state=args.random_state, stratify=df['room_type']
    )

    pre = build_preprocessor()

    ridge = Pipeline([('preprocess', pre), ('model', Ridge(alpha=1.0, random_state=42))])
    rf = Pipeline([('preprocess', pre), ('model', RandomForestRegressor(
        n_estimators=args.n_estimators,
        min_samples_split=4,
        min_samples_leaf=2,
        n_jobs=-1,
        random_state=args.random_state
    ))])

    ridge.fit(X_train, y_train)
    rf.fit(X_train, y_train)

    out = {}
    for name, model in [('Ridge', ridge), ('RandomForest', rf)]:
        y_pred = model.predict(X_test)
        out[name] = evaluate(y_test, y_pred)

    os.makedirs(args.report_dir, exist_ok=True)
    pd.DataFrame([{'model':k, **v} for k,v in out.items()]).to_csv(
        os.path.join(args.report_dir, 'regression_metrics.csv'), index=False
    )

    joblib.dump(ridge, os.path.join(args.model_dir, 'ridge_pipeline.joblib'))
    joblib.dump(rf, os.path.join(args.model_dir, 'rf_pipeline.joblib'))

    print(json.dumps(out, indent=2))

if __name__ == '__main__':
    p = argparse.ArgumentParser()
    p.add_argument('--data', type=str, required=True)
    p.add_argument('--target', type=str, default='price')
    p.add_argument('--auto-clean', action='store_true')
    p.add_argument('--test-size', type=float, default=0.2)
    p.add_argument('--random-state', type=int, default=42)
    p.add_argument('--n-estimators', type=int, default=150)
    p.add_argument('--report-dir', type=str, default='reports')
    p.add_argument('--model-dir', type=str, default='.')
    args = p.parse_args()
    main(args)
