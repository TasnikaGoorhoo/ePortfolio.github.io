Step 2: Second Normal Form (2NF)

2NF Requirements:

  • The table must be in 1NF.
  • All non-key attributes must be fully functionally dependent on the primary key.

Transformation: We will separate the data into different tables to eliminate partial dependencies. The primary key will be a combination of Student Number and Course Name.

Unit 10 Artefacts:

Example of API chosen: RESTful API for accessing financial data

Requirements include:

1. Authentication and Authorization

  • Requirement: Implementation of OAuth 2.0 for secure authentication.
  • Mitigation: Ensures only authorized users can access the API, reducing unauthorized data access.

2. Data Encryption

  • Requirement: Using TLS (Transport Layer Security) for data in transit.
  • Mitigation: Protects sensitive data being accessed through this process and prevents man-in-the-middle attacks during transmission.

3. Input Validation

  • Requirement: Validating all inputs from users to prevent injection attacks.
  • Mitigation: Ensures only well formatted data is processed, reducing the risk of malicious data manipulation.

4. Data Privacy

  • Requirement: Ensuring compliance with data protection regulations (e.g., GDPR).
  • Mitigation: Protects user data and builds trust with users regarding data handling practices.
